## 3. Input / Output Tensor Shapes

### 3.1 PyTorch Inference (`.pt`)

Both models accept standard YOLO input:
- **Input**: `[1, 3, 640, 640]` — batch × channels × height × width (RGB, normalized 0–1)

### 3.2 ONNX Tensor Shapes

#### Model A — Detection ONNX (`detect_product_empty_space.onnx`)

| Tensor | Name | Shape | Description |
|---|---|---|---|
| Input | `images` | `[1, 3, 640, 640]` | RGB image, batch=1 |
| Output | `output0` | `[1, 6, 8400]` | 8400 anchors × (4 bbox coords + 2 class scores) |

**Output0 layout per anchor (dim=1 axis):**
```
[x_center, y_center, width, height, score_class0_empty, score_class1_product]
```
To decode: take argmax of scores[4:6] for class, apply confidence threshold (e.g. 0.25), then apply NMS.

#### Model B — Segmentation ONNX (`segment_shelf_rows.onnx`)

| Tensor | Name | Shape | Description |
|---|---|---|---|
| Input | `images` | `[1, 3, 640, 640]` | RGB image, batch=1 |
| Output | `output0` | `[1, 37, 8400]` | 8400 anchors × (4 bbox + 1 class + 32 mask coefficients) |
| Output | `output1` | `[1, 32, 160, 160]` | Prototype masks (32 protos at 160×160 resolution) |

**Output0 layout per anchor (dim=1 axis):**
```
[x_center, y_center, width, height, score_class0_row, mask_coeff_0..31]
```
**Mask reconstruction:** `final_mask = sigmoid(mask_coefficients @ proto_masks.reshape(32, 160*160)).reshape(160, 160)` then upsample to original image size.

## 4. Architecture Details

### YOLO11n (Detection — Model A)
- Nano variant of Ultralytics YOLO11 family
- ~2.6M parameters, optimized for edge/mobile deployment
- Single-stage anchor-free detection head
- Output: 8400 candidate boxes (anchors at 3 scales: 80×80, 40×40, 20×20)
- Backbone: C3k2 + SPPF + C2PSA feature pyramid

### YOLO11n-seg (Segmentation — Model B)
- Nano segmentation variant — same backbone as YOLO11n
- Adds a **mask head**: outputs 32 prototype masks (160×160) + 32 mask coefficients per anchor
- Instance segmentation: each detected row gets a pixel-accurate mask
- Heavier than detection model by ~1 MB due to mask decoder
